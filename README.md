# Projet Django de Visualisation Interactive des Équations

Ce projet permet de tracer des graphiques d'équations mathématiques simples grâce à une interface web interactive.

## Fonctionnalités

- Saisie d'équations sous forme de texte.
- Génération de graphiques à l'aide de matplotlib.
- Visualisation dynamique dans le navigateur Web.
