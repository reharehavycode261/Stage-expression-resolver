# Visualisation Interactive des Équations

Cette application web Django permet aux utilisateurs d'entrer des équations mathématiques et de visualiser leurs graphiques.

## Fonctionnalités

- Interface utilisateur pour entrer une équation en fonction de `x`.
- Graphique généré pour les équations courantes.
- Utilisation de bibliothèques scientifiques (Numpy, Matplotlib) pour le rendu précis des graphiques.
