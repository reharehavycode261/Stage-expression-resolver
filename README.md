# Projet S4_IA

Bienvenue dans le projet S4_IA. Ce projet contient diverses fonctionnalités liées à l'application S4, y compris la gestion de numéros, l'analyse d'expressions et bien d'autres.

## Fonctionnalités

- **Gestion de numéros**: Fonctions pour vérifier et prioriser les opérateurs dans les expressions numériques.
- **Analyse d'expressions**: Validation des caractères et conversion en types numériques.

## Structure du projet

- **/number**: Contient les modules relatifs aux opérations numériques.
- **/S4_IA**: Le cœur du projet Django, incluant la configuration des URL et les paramètres de l'application.

## Installation

Pour installer ce projet, veuillez cloner ce dépôt et installer les dépendances nécessaires via pip.
